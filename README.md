## Project Overview

**AR Card Wars** is an augmented reality experience inspired by *Card Wars* from *Adventure Time*. This game combines physical trading cards with immersive digital gameplay. Players scan physical cards using a mobile device, bringing creatures and spells to life in AR.

The app handles all core gameplay logic—such as turn structure, player health, and card effects—while physical cards serve as anchors in the real world, enhancing immersion. The result is a fully interactive, highly visual game that bridges physical and digital play.

---

## Use Case

AR Card Wars is designed for casual and competitive two-player matches. The game:
- Animates physical cards in augmented reality
- Automatically manages turns and game state
- Delivers a hands-on, visual experience for fans of tabletop card games

## Technology Stack

### AR Framework / SDK
- **Unity AR Foundation**  
  Cross-platform AR built on ARKit (iOS) and ARCore (Android)

### Tracking Techniques
- **Image Tracking**  
  Physical cards act as image targets, anchoring AR content in the real world

### Development Tools / Platforms
- **Unity Engine** (2022.x or newer)  
- **C#** for gameplay and logic scripting
- **XR** for overall AR gameplay
- **Visual Studio** for IDE
- **Visual Studio Code** for IDE
- **Android** for running the app
- **Git/GitHub** for version control
